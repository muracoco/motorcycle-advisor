# Motorcycle Advisor

## 開発終了（2026年11月3日）

2026年11月3日時点の最終状態を保存し、開発・保守を終了しました。このリポジトリは参照用のアーカイブです。

バイク選び支援の単体プロトタイプの最終保存版です。個人HP内に組み込んだ版は今回の終了・削除の対象外です。

保存範囲・確認結果は [ARCHIVE_STATUS.md](ARCHIVE_STATUS.md) を参照してください。


身体情報・経験・好みをもとに、仮の評価ルールでオートバイの候補を絞り込むプロトタイプです。

判断ロジックと画面構成を依存なしの静的 Web アプリとして実装しています。
初期データとして88車種を収録しています。

## 目的

- ユーザーの身体情報と経験からライダーランクを算出する
- 好みの条件に合うオートバイを検索する
- 仮ルール上でライダーランクや身長ランクを超える車種を除外する
- 将来的なバイクデータ拡充に備え、判断ロジックとデータを分離する

## 起動方法

ES modules を使っているため、`index.html` の直接起動（`file://`）では Chrome などのブラウザで読み込みが制限されます。ローカルの HTTP サーバー経由で開いてください。アプリの依存パッケージやビルドは不要です。

Python 3 がインストールされている場合、標準の HTTP サーバーを利用できます。

### Windows（PowerShell）

保存先に合わせてパスを変更し、実行します。

```powershell
Set-Location .\motorcycle-advisor
py -3 -m http.server 8000 --bind 127.0.0.1
```

`py` が使えず `python --version` で Python 3 が確認できる場合は、2行目を `python -m http.server 8000 --bind 127.0.0.1` に置き換えてください。

### macOS / Linux

```sh
cd /path/to/motorcycle-advisor
python3 -m http.server 8000 --bind 127.0.0.1
```

起動したターミナルを開いたまま、ブラウザで <http://127.0.0.1:8000/> にアクセスします。ポートが使用中なら、コマンドと URL の `8000` を両方 `8001` などへ変更してください。`--bind 127.0.0.1` により、このPCからのみアクセスできます。

停止するときは、サーバーを起動したターミナルで `Ctrl+C` を押します。ブラウザを閉じるだけでは停止しません。

年齢（16～90歳）、身長（120～220cm）、体重（30～180kg）は整数で入力します。空欄や範囲外などの無効な入力がある間は、候補とランクを消して訂正を案内します。有効な値への訂正、または「初期値に戻す」で再計算します。

## テスト

Node.js が使える環境で以下を実行します。

```bash
npm test
```

UI変更時は `tests/manual-checklist.md` も確認してください。

- `data/bikes.js`: 代表車種の初期データ

## 公開データ方針

このリポジトリには、機密情報や実在個人の情報を含めない方針です。詳細は `SECURITY.md` を参照してください。

## 現時点の制限

- ランク・目安スコア・ランク差は仮ルールの計算結果であり、実測の適合性や足つきを示しません。年齢・性別・体格に対する係数の妥当性は未検証です。
- 免許条件を判定する機能はなく、運転の安全性や購入判断の正しさを保証しません。実車の足つき・取り回しや仕様は、販売店やメーカー資料などで別途確認してください。
- 収録88件の出典URL・確認日・販売状態は未確認です。最新の車種一覧・実車スペックとしては利用できません。
- `power`、`weight`、`sheet` などは段階評価であり、馬力・kg・mmなどの実測値ではありません。値の定義は [仕様メモ](docs/spec.md#車種データ) を参照してください。
- ログイン、ユーザー保存、車種追加機能は未実装です。
- 入力した個人情報はブラウザ内の計算にのみ使い、保存・外部送信しません。
