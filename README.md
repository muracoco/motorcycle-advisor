# Motorcycle Advisor

身体情報・経験・好みをもとに、扱いやすいオートバイを絞り込むプロトタイプです。

判断ロジックと画面構成を依存なしの静的 Web アプリとして実装しています。

## 目的

- ユーザーの身体情報と経験からライダーランクを算出する
- 好みの条件に合うオートバイを検索する
- ライダーランクや身長ランクを超える扱いにくい車種を除外する
- 将来的なバイクデータ拡充に備え、判断ロジックとデータを分離する

## 起動方法

`index.html` をブラウザで開くと動作します。外部依存はありません。

## 構成

- `index.html`: 画面本体
- `src/app.js`: UI制御
- `src/ranking.js`: ライダーランク・車種ランク算出
- `src/recommendation.js`: 条件フィルタと推薦ロジック
- `src/styles.css`: 画面スタイル
- `data/bikes.js`: 代表車種の初期データ
- `docs/spec.md`: 仕様メモ
- `tests/manual-checklist.md`: 手動確認項目

## 現時点の制限

- バイクデータは代表車種のみです。
- メーカー・車種スペックは初期検証用のコード化データを使っています。
- ログイン、ユーザー保存、車種追加機能は未実装です。
