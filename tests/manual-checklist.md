# Manual Checklist

## 基本動作

- READMEの手順でローカル HTTP サーバーを起動し、`http://127.0.0.1:8000/` を開くと入力フォームが表示される
- 初期値のまま結果が表示される
- 入力値や選択肢を変更すると、ボタン操作なしで結果が更新される
- ライダーランク、身長ランク、補正後スコアが表示される
- 表示結果は仮ルール上でライダーランクを超える車種を含まない
- ランクトラックで現在ランクと絞り込み対象のランクが視覚的に分かる

## 入力検証

- 年齢・身長・体重を1項目ずつ空欄にすると、項目名と訂正メッセージが表示され、直前の候補・集計・ランクが消える
- 年齢15 / 91、身長119 / 221、体重29 / 181でも同じ状態になる
- 小数（例: 身長179.5）や数値として未完成の入力でも計算結果が残らない
- 無効な入力のまま並び替え・好みを変更しても結果が復活せず、「条件に合う車種がありません」と混同しない
- 年齢16 / 90、身長120 / 220、体重30 / 180は入力範囲内として計算される（候補0件の場合を含む）
- 有効な整数に戻すと訂正メッセージが消え、候補・集計・ランクが更新される
- 無効な入力から「初期値に戻す」を押すと、初期値で再計算される

## 条件変更

- メーカーを変更すると結果が絞り込まれる
- 排気量上限を下げると大型車が除外される
- 身長を低くするとシート高の高い車種が除外される
- 運動経験・搭乗経験を下げると高ランク車種が除外される
- 並び替えを変更するとカードの順序が変わる

## 空結果

- 条件を厳しくしすぎた場合、空結果メッセージが表示される

## 仕様観点

- 利用者情報の入力項目が揃っている
- 好み選択がメーカー、ギア、排気量、タイプ、積載性、燃費を含んでいる
- 仮ルールによる目安であり、実際の足つき・適合性・安全性を示さないことが画面に明記されている
- 車種カードが「目安スコア」「ランク差」「シート高ランク」と表示され、実測値と混同しない
- `data/bikes.js` に88車種が実装されている
- デスクトップ・モバイル幅で、訂正メッセージや変更したラベルが重ならずに読める
- サーバーを起動したターミナルで `Ctrl+C` を押すと停止する
