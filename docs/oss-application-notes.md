# Codex for Open Source 申請メモ

## 現状評価

このリポジトリは、身体情報・経験・好みをもとに扱いやすいオートバイを推薦する静的Webアプリのプロトタイプです。

現時点では、スター数、フォーク数、Issue、Pull Request、リリース実績が少ないため、「広く利用されているOSS」としての実績は弱いです。一方で、二輪初心者や復帰ライダーの車種選びを安全側に支援するドメイン特化OSSとして、車種データ拡充、推薦ロジック改善、出典管理、レビュー運用を継続する余地があります。

## 申請時に説明しやすい点

- 依存なしの静的Webアプリで、誰でもブラウザで確認できる。
- 判断ロジック、車種データ、UIが分離されており、レビュー対象が明確。
- ロジックテストと手動チェックリストがある。
- 車種データの追加・修正に対して、出典確認や安全側のレビューが必要。

## 申請時の弱点

- 利用実績がまだない。
- IssueトリアージやPRレビューの履歴がまだない。
- リリースがまだない。
- 車種データの出典・更新日・販売状態が未整備。

## 改善ロードマップ

1. GitHub Pagesでデモを公開する。
2. `v0.1.0` の初回リリースを作成する。
3. 車種データに出典、確認日、販売状態を追加する。
4. Issueでロードマップとデータ追加タスクを管理する。
5. PRテンプレートにテスト確認と出典確認を必須項目として運用する。
6. 推薦ロジックの根拠を仕様書に追記し、レビュー可能にする。

## 申請文のたたき台

このプロジェクトは、ライダーの身体情報・経験・好みに基づき、扱いにくい可能性のある車種を安全側に除外して推薦する静的Webアプリです。現時点ではプロトタイプですが、二輪初心者や復帰ライダーの車種選びを支援するOSSとして、車種データの出典管理、推薦ロジックの改善、Issueトリアージ、PRレビュー、リリース管理を継続的に行う予定です。Codexは、車種データ追加PRのレビュー、仕様とテストの整備、リリース作業、セキュリティ・個人情報混入チェックに活用したいです。
