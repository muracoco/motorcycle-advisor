# 仕様メモ

## システム概要

オートバイに乗ろうとしている、または乗り換えを検討しているユーザー向けの推薦システム。

ユーザーは身体情報と経験情報を入力し、その後に好みの条件を選択する。システムはユーザー情報からライダーランクと身長ランクを算出し、好みに合う車種のうち、ユーザーが扱いきれない可能性のある車種を除外して表示する。

## 入力

トップページ相当の入力:

- 名前
- 年齢
- 性別
- 身長
- 体重
- 運動経験
- 搭乗経験

好み選択:

- メーカー
- トランスミッション
- 排気量
- タイプ
- 積載性
- 燃費

## ライダーランク算出

年齢別の反復横跳びデータをベース値にする。

- 20歳: 52.88
- 25歳: 51.12
- 30歳: 49.70
- 35歳: 48.43
- 40歳: 47.38
- 45歳: 45.68
- 50歳: 44.11
- 55歳: 40.60
- 60歳: 37.84
- 65歳: 35.08
- 70歳: 31.32
- 75歳: 26.56
- 80歳: 20.80

5歳刻みの表値を使い、入力年齢以下で最も近い値を採用する。

補正:

- ローレル指数が標準: `1.0`
- 痩せ気味・太り気味: `0.9`
- 痩せすぎ・太り過ぎ: `0.8`
- 性別: 男性 `1.0`、女性 `0.88`
- 運動経験: `0.7, 0.85, 1.0, 1.1, 1.2`
- 搭乗経験: `0.7, 0.85, 1.0, 1.1, 1.4`

年齢別ベース値を男性基準として扱い、女性は反復横跳び等の性別差を吸収する保守的な係数として `0.88` を掛ける。

ランク:

- 70以上: A
- 52以上: B
- 46以上: C
- 38以上: D
- 31以上: E
- 30以下: F

## 身長ランク

- 176cm以上: 5
- 170cm以上: 4
- 165cm以上: 3
- 161cm以上: 2
- 160cm以下: 1

## 車種データ

車種テーブル:

- id
- name
- maker
- gear
- displacement
- cylinder
- power
- weight
- genre
- loading
- sheet
- style
- fuel
- wind
- diff
- rank

車種難易度 `diff` は「出力、重量、シート高、前傾」から算出される。

```text
diff = power + weight + sheet + style
```

車種ランク:

- 21以上: A
- 18以上: B
- 16以上: C
- 13以上: D
- 10以上: E
- 9以下: F

## 推薦条件

以下をすべて満たす車種を表示する。

- 選択したメーカーに一致する
- 選択したトランスミッションに一致する
- 車種排気量が選択した上限以下
- 選択したタイプに含まれる
- 積載性が選択条件以上
- 燃費が選択条件以上
- 車種ランクがライダーランク以下
- 車種のシート高ランクが身長ランク以下

## 今後の論点

- 本格データ投入時は、車種スペックの出典・更新日・販売状態を持たせる必要がある。
- ログイン機能、ユーザー情報保存、車種追加機能は未実装。

## 公開・運用方針

- 推薦ロジックの変更は、ロジックテストと手動チェックリストで確認する。
- 車種データの追加・修正は、出典URL、確認日、販売状態を記録してレビューする。
- 個人情報、APIキー、トークン、非公開資料、ライセンス不明のデータは含めない。
- Issueは不具合、車種データ更新、仕様改善に分けてトリアージする。
