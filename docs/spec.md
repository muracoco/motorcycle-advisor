# 仕様メモ

## システム概要

オートバイに乗ろうとしている、または乗り換えを検討しているユーザー向けの候補検索プロトタイプ。

ユーザーは身体情報と経験情報を入力し、その後に好みの条件を選択する。システムは仮の評価ルールでライダーランクと身長ランクを算出し、ランクと好みの条件を満たす車種を表示する。

## 評価とデータの限界

- ランク・目安スコア・ランク差は実測の適合性や足つきを表さない。年齢・性別・体格に対する係数の妥当性は未検証。
- 免許条件の判定は行わず、運転の安全性や購入判断の正しさを保証しない。実車の足つき・取り回しや仕様は別途確認が必要。
- 現在の88件について、出典URL・確認日・販売状態は未確認。最新のスペックや販売中であることを保証するデータではない。
- 個人入力はブラウザ内の計算にのみ使用し、保存・外部送信しない。

## 入力

トップページ相当の入力:

- ニックネーム（任意。評価には使用しない）
- 年齢（必須、16～90歳の整数）
- 性別
- 身長（必須、120～220cmの整数）
- 体重（必須、30～180kgの整数）
- 運動経験
- 搭乗経験

HTMLの `required`・`min`・`max`・数値入力の既定の `step=1` と `form.checkValidity()` で検証する。無効な入力がある場合は計算せず、既存の候補・集計・ランク表示を消して、最初の無効な項目と入力できる範囲を表示する。有効な値への訂正、またはリセット後に再計算する。入力範囲自体も、運転できる条件を定めるものではない。

好み選択:

- メーカー
- トランスミッション
- 排気量
- タイプ
- 積載性
- 燃費

5歳刻みの表値を使い、入力年齢以下で最も近い値を採用する。20歳未満は20歳の値、80歳以上は80歳の値を使う。

補正:

- ローレル指数が116超145以下: `1.0`
- ローレル指数が100超116以下、または145超160以下: `0.9`
- ローレル指数が100以下、または160超: `0.8`
- 性別: 男性 `1.0`、女性 `0.85`
- 運動経験: `0.7, 0.85, 1.0, 1.1, 1.2`
- 搭乗経験: `0.7, 0.85, 1.0, 1.25, 1.4`

年齢別ベース値にローレル指数、運動経験、搭乗経験を掛け、身長ランクを足した後に性別係数を掛ける。

```text
score = (baseScore * rohrerMultiplier * exerciseMultiplier * ridingMultiplier + heightRank) * genderMultiplier
```

## 車種データ

`data/bikes.js` の `bikes` 配列に88件を収録している。各要素は次の全フィールドを持つオブジェクトとする。数値は文字列にせず、整数の `number` で保存する。

| フィールド | 型・範囲 / enum | 意味・単位 |
| --- | --- | --- |
| `id` | 整数、1～`Number.MAX_SAFE_INTEGER`、配列内で一意 | 識別子。連番である必要はない。単位なし |
| `name` | 空文字・空白だけでない `string`、前後の空白なし | 車種名。同じ `maker` と `name` の組は重複不可 |
| `maker` | `string`: `ホンダ` / `スズキ` / `ヤマハ` / `カワサキ` | 現在対応するメーカー名 |
| `gear` | 整数: `1` / `2` | `1`=MT、`2`=AT。区分コードであり変速段数ではない |
| `displacement` | 整数: `1`～`7` | 排気量区分。`1`=50cc以下、`2`=125cc以下、`3`=250cc以下、`4`=400cc以下、`5`=750cc以下、`6`=1000cc以下、`7`=無制限（上限なし）。保存値自体はccではない |
| `cylinder` | 整数: `1` / `2` / `3` / `4` / `6` | 現在収録する気筒数。単位は気筒。評価式には未使用 |
| `power` | 整数: `1`～`10` | 出力の段階評価。大きいほど難易度に加算。PS・kWではない |
| `weight` | 整数: `1`～`5` | 重量の段階評価。大きいほど難易度に加算。kgではない |
| `genre` | 整数: `1`～`6` | `1`=スクーター、`2`=アメリカン、`3`=ネイキッド、`4`=スポーツ、`5`=オフロード、`6`=ツアラー |
| `loading` | 整数: `1`～`5` | 積載性の段階評価。順に少ない / やや少ない / 普通 / 多い / かなり多い。L・kgではない |
| `sheet` | 整数: `1`～`5` | シート高ランク。大きいほど難易度に加算し、身長ランクと比較する。mm・cmではない。キー名は既存の `sheet` を維持 |
| `style` | 整数: `1`～`5` | 前傾姿勢の段階評価。大きいほど難易度に加算。角度ではない |
| `fuel` | 整数: `1`～`5` | 燃費の段階評価。順に低い / やや低い / 普通 / 良い / とても良い。km/Lではない |
| `wind` | 整数: `1`～`5` | 風防の段階評価。順に低い / やや低い / 普通 / 高い / かなり高い。物理単位なし |

これは既存コードとラベルに対応したデータ形式であり、各段階の実測値への換算境界は未整備。実スペックから評価値を推測して埋めない。追加時は出典URL・確認日・販売状態に加え、対象年式・仕様と評価値の根拠をIssueまたはPR本文で示す。未確認の項目は未確認と記載する。enumや値域を拡張する場合は、対応する入力選択肢・ラベル・テスト・この定義も見直す。

車種難易度指数 `diff` は「出力、重量、シート高、前傾」の段階評価の合計であり、実測の難易度ではない。`diff`（整数、4～25）と `rank`（`A` / `B` / `C` / `D` / `E` / `F`）は `enrichBike()` が計算するため、元データには保存しない。

```text
diff = power + weight + sheet + style
```

- 21以上: A
- 18以上: B
- 16以上: C
- 13以上: D
- 10以上: E
- 9以下: F

## 推薦条件

以下をすべて満たす車種を表示する。

- 選択したメーカーに一致する
- 選択したトランスミッションに一致する
- 車種排気量が選択した上限以下
- 選択したタイプに含まれる
- 積載性が選択条件以上
- 燃費が選択条件以上
- 車種ランクがライダーランク以下
- 車種のシート高ランクが身長ランク以下

画面の「ランク差」はライダーランクと車種ランクを `F=1`～`A=6` に置き換えた差。「身長・シート高ランク差」は身長ランクから `sheet` を引いた値。いずれも安全上の余裕ではない。

「目安スコア」は次の既存式を四捨五入した値。適合率や確率ではなく、100を超える場合もある。

```text
45 + ランク差 * 12 + 身長・シート高ランク差 * 7
   + fuel * 3 + loading * 2 + max(0, 24 - diff)
```

## 今後の論点

- 本格データ投入時は、車種スペックの出典・更新日・販売状態を持たせる必要がある。
- ログイン機能、ユーザー情報保存、車種追加機能は未実装。

## 公開・運用方針

- 推薦ロジックの変更は、ロジックテストと手動チェックリストで確認する。
- 車種データの追加・修正は、出典URL、確認日、販売状態を記録してレビューする。
- 個人情報、APIキー、トークン、公開できないデータ、ライセンス不明のデータは含めない。
- Issueは不具合、車種データ更新、仕様改善に分けてトリアージする。
